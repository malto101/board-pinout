SoC pad table

SoC authoring flow
1. Define the table identity. 2. Add canonical pads and aliases. 3. Add intrinsic electrical data and functions. 4. Link this table from a board and choose pads on its parts. 5. Export both documents.

Canonical names are stored on board parts; aliases are lookup names. Inherited pad and mux data is read-only here and remains sourced from the SoC table.
