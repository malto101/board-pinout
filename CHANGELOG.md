# Changelog

All notable changes to Board Pinout are documented here.

## [Unreleased]

- Continue improving board and SoC-table authoring in the hosted editor.

## [0.2.0a1] - 2026-10-15

- Prepared the prerelease package with deterministic wheel and sdist metadata validation.
- Added CI coverage for clean artifact staging and isolated package smoke tests.
- Hardened TestPyPI and PyPI publishing around trusted, explicitly staged distributions.

## [0.2.0] - 2026-10-11

- Restored reusable SoC pad-table validation and board resolution.
- Added `diff` and `soc-pads validate` CLI commands.
- Added SoC fixtures and widget-index benchmark coverage.
- Published the Vite editor below the documentation site on GitHub Pages.
- Added canonical package versioning, contributor guidance, and security policy.
