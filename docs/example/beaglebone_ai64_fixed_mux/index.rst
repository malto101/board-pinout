BeagleBone AI-64 dense fixed-mux sample
========================================

This sample uses the real BeagleBone AI-64 board artwork and a dense 2x20
header. The J721E table describes fixed per-pad ``mode`` values, including the
UART and I2C assignments from the Zephyr board pinctrl file. Dense labels and
many neighboring markers make the viewer's collision-aware layout visible.
