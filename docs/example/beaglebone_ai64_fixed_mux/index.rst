BeagleBone AI-64 dense fixed-mux sample
========================================

This sample places all 92 P8/P9 contacts on the front-facing BeagleBone AI-64
photograph, measured from the socket grid (odd pins on the lower row, pin 1 at
the left). The J721E table lists every header pad's MODE 0-14 functions from
the BeagleBoard.org expansion tables, including the Zephyr UART2 console and
I2C6 assignments. Labels use two column-aligned bands with leader waypoints so
the dense header stays readable.
