ZedBoard — Zynq-7000 XC7Z020
=============================

This sample represents the PS MIO signals used by Zephyr's ZedBoard target:
UART1 on MIO48/MIO49, the LD_MIO LED on MIO7, and pushbuttons on MIO50/MIO51.
The focused table retains the Zynq UART pin group and LVCMOS18 metadata.
