NPCX9 signal-select sample
===========================

This sample demonstrates signal-owned ``DEVALT`` selection. UART1 input and
output signals each have candidate pads selected by ``SL1`` or ``SL2``; the
I2C and ADC entries show that selection is not an alternate-function index on
the pad itself.
